To implement the feature of user-customizable dashboard aesthetics in Velvue, we need to make changes both on the backend (Laravel) and the frontend (Vue.js). Here's a step-by-step plan to achieve this:

### Backend (Laravel - be_velvue)

1. **Data Model and Migration:**
   - Create a new Eloquent model `UserDashboardPreference`.
   - Create a migration to add a table for storing `accent_color` and `background_image_path` with a one-to-one relationship with the `User` model.

2. **API Endpoint:**
   - Add a new method in `AccountController.php` to handle saving/updating user preferences.
   - Ensure the endpoint is authenticated.

3. **Image Handling Protocol:**
   - Validate `background_image_path` using `App\Rules\TemporaryFileExists`.
   - Handle the deletion of `TemporaryUpload` records and any existing background images when a new image is set or cleared.

4. **User Data Service:**
   - Update `AuthController.php` to include `dashboard_preference` in the authenticated user data response.

### Frontend (Vue.js - fe_velvue)

1. **Settings Interface (AccountPage.vue):**
   - Add a "Dashboard Appearance" section.
   - Integrate a `ColorPicker` for `accent_color`.
   - Implement `FileUpload` for `background_image` using the `/api/upload` endpoint with `entity: 'dashboard_backgrounds'`.
   - Add functionality to save preferences by calling the new backend API endpoint.

2. **State Management (auth.js - Pinia):**
   - Fetch and store `dashboard_preference` with user data in `authStore`.
   - Update the store upon successful save of preferences.

3. **Dynamic Styling Application (AppLayout.vue):**
   - Override the PrimeVue Aura theme's primary color CSS variable with the selected `accent_color`.
   - Display the `background_image_path` on the main dashboard content area.
