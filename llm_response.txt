To implement the feature for user-customizable dashboard aesthetics in Velvue, we need to make changes both on the backend (Laravel) and the frontend (Vue.js). Here's a step-by-step plan to achieve this:

### Backend (Laravel - `be_velvue`)

1. **Data Model and Migration:**
   - Create a new Eloquent model `UserDashboardPreference` with fields `accent_color` and `background_image_path`.
   - Create a migration to add a new table for `user_dashboard_preferences` with a one-to-one relationship with the `User` model.

2. **API Endpoint:**
   - Add a new method `updateDashboardPreferences` in `AccountController.php` to handle saving/updating user preferences.
   - Define a new route in `api.php` for this method, ensuring it is protected by authentication middleware.

3. **Image Handling Protocol:**
   - Ensure the `background_image_path` references a file processed by the temporary upload system.
   - Use `App\Rules\TemporaryFileExists` for validation.
   - Delete the `TemporaryUpload` record and any previously existing background image file upon successful update.

4. **User Data Service:**
   - Update the method in `AuthController.php` that returns authenticated user data to include the `dashboard_preference` object.

### Frontend (Vue.js - `fe_velvue`)

1. **Settings Interface (`AccountPage.vue`):**
   - Add a "Dashboard Appearance" section with a `ColorPicker` for `accent_color`.
   - Implement a `FileUpload` component for `background_image`, using the `/api/upload` endpoint with `entity: 'dashboard_backgrounds'`.
   - Provide UI for image preview and removal.
   - Add functionality to save preferences by calling the new backend API endpoint.

2. **State Management (`auth.js` - Pinia):**
   - Fetch and store `dashboard_preference` with user data in `authStore`.
   - Update the store reactively upon successful save.

3. **Dynamic Styling Application (`AppLayout.vue`):**
   - Override the PrimeVue Aura theme's primary color CSS variable with the selected `accent_color`.
   - Apply the `background_image_path` to the main dashboard content area.
